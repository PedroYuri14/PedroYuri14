# Java IDE — PedroYuri14

## Style Prompt
An accurate, restrained Java workspace inspired by IntelliJ IDEA and GitHub Dark.
The code is the central subject. A compact project tree, editor chrome and terminal
provide context. Text is typeset, never generated as an illustration. At 0–2 s the
workspace opens; at 2–9 s Java is typed; at 9–12 s compilation and execution complete;
at 12–15 s a gentle pullback and dissolve return to the opening frame.

## Colors
- Canvas: `#0D1117`
- Surfaces: `#161B22`
- Primary text: `#E6EDF3`
- Selection and types: `#58A6FF`
- Success and strings: `#3FB950`
- Java keywords: `#BC8CFF`

## Typography
JetBrains Mono, bundled locally under the SIL Open Font License. Disable code
ligatures. Code is 27 px at a 1600 × 900 production resolution.

## Motion
Deterministic 15-second timeline, no audio. Smooth 0.4–0.8 s interface transitions;
natural character cadence with extra pauses at line boundaries. Terminal expands
without covering the final code. Camera pullback is at most 1.5%.

## What NOT to Do
- No neon wash, game sprites or decorative pseudo-code.
- No invented build output or invalid Java.
- No JavaScript embedded in the profile README.
- No hard cut across the loop boundary.
